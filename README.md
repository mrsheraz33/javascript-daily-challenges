# JavaScript Daily Practice & Core Concepts

This repository contains my practical JavaScript implementations, logic building exercises, and DOM manipulation tasks. It demonstrates foundational web development concepts written in clean Vanilla JS (ES6+).

---

## Practical Concepts Covered

| Task / Feature | Core Concepts Applied | Key Mechanics |
| :--- | :--- | :--- |
| **Character Counter** | DOM Events, Conditional Styling | Real-time input length checking with visual color indicators |
| **API Post Fetcher** | Async/Await, Fetch API, DOM Creation | Error handling, dynamic list rendering, loading states |
| **Debounced Array Search** | Debouncing, Higher-Order Functions, Filtering | Performance optimization by delaying execution during user input |
| **Array Pagination** | Array Slicing, State Management | Multi-page data navigation using dynamic start/end indices |
| **Infinite Scroll Listener** | Browser Events, Window Geometry | Triggering action when user scrolls to bottom of page |
| **Debounced Dynamic API Search** | API Fetching, Debouncing, Dynamic Filtering | Optimizing API requests based on debounced search queries |

---

## Technical Highlights

* **Performance Optimization:** Applied custom Debounce closures to restrict frequent function invocation on search inputs.
* **Asynchronous Handling:** Used native `fetch` with `async/await` and `try/catch` blocks for robust API error handling.
* **Dynamic DOM Scripting:** Utilized `document.createElement`, `append`, and dynamic inline styling without external libraries.
* **Data Manipulation:** Manipulated datasets using array methods (`map`, `filter`, `slice`).
